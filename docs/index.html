Bolt PDF

Bolt PDF is a fast, lightweight Android PDF & Markdown reader powered by a native Rust + PDFium engine, supporting smooth reading, RTL/LTR text selection, highlights, PDF tools (merge, split, images to PDF), and optional private Google Drive sync.

  • Fast native PDF rendering and full-text search
  • PDF Merge, Split, and Images-to-PDF tools
  • English & Arabic UI with full RTL support
  • Optional private Google Drive sync for your files, reading progress, and favorites
